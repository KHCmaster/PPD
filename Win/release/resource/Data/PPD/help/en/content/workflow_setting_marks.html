So far you have only placed the marks. Next, set the position, angle and kind of the marks.
First, how to position marks.
To position them intuitively, select a mark and drag it in the game window.


If you want to restrict where marks can be placed, you can use the grid.
While the grid is shown, the mouse can only place marks on grid intersections. (Toggle it with the grid button)


To fine-tune a mark's position, use the arrow keys. (1px normally, 10px with Shift, 5px with Control. Changeable in the settings)
To copy the position of the previous mark of the same kind, press Ctrl+Q.
You can also simplify positioning with the Position/Angle Loader Saver or the Geometry Creator, but they are skipped here since this guide is for beginners.

Next, the angle of marks.
After selecting a mark, drag anywhere in the game window except on the mark to set its angle.
Holding Shift restricts the angle to multiples of a certain angle. (10 degrees by default. Changeable in the settings)


To copy the angle of the previous mark of the same kind, press Ctrl+R.
Likewise, you can simplify this with the Position/Angle Loader Saver or the Geometry Creator, but they are skipped here since this guide is for beginners.

Next, the kind of marks.
As explained, the kind of a mark depends on the vertical position where it is placed.
To change the kind of a placed mark, drag it while holding Shift and drop it at the vertical position of the kind you want.
Dragging and dropping while holding Ctrl copies the mark.
Alternatively, select a range and copy it with Ctrl+C; when you then place a mark, the copy is placed at that position. (Don't forget to clear the copy buffer with Ctrl+Shift+C)

Next, how to create long notes (or HOLDs).
Place a mark at the start of the long note (the start of the HOLD).
Then place a mark at the end of the long note (for a HOLD, before the next mark of the same kind) and select both with a range selection.
Press Ctrl+F to turn them into a long note (HOLD).
With a long note selected, press Ctrl+Shift+F to split it.
