Suppose the score is now complete. Create the data to distribute.
Select File → Publish.


The following dialog appears. Check the difficulties you want to distribute.
The default publish folder should be fine.
Enter the score name as the publish folder name (the project name is filled in by default, so it should be fine as is).


Press OK to finish publishing. The publish folder is then shown, so compress that folder into a zip file and upload it to an uploader.
Before uploading, put it in the songs folder of your own PPD and check that the thumbnail, information and so on are displayed correctly.
