We haven't mentioned it yet, but the difficulty you have been working on so far is Base, which is none of the four difficulties (easy, normal, hard, extreme).
As the name suggests, Base is a difficulty for creating the base of the score. The developer intends you to copy it to other difficulties and change the kinds of marks and so on to add difficulties.
Also, Base itself can't be played, so you need to copy it to some difficulty.

Let's copy the Base difficulty to the Normal difficulty.
Select Difficulty → Copy Current Difficulty.


Then set the combo box in the dialog to Normal and press OK.


At this point it has only been copied, so switch the difficulty to edit the score in Normal.


You can tell the current difficulty by clicking the Difficulty menu, or from the title of the PPDEditor main window, which looks like "score name(Normal) - PPDEditor".
Note that history such as undo is lost when you switch difficulties.
