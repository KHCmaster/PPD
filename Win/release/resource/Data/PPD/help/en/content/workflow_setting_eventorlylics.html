This section explains how to set up lyrics. Show the Lyrics Editor from View → Lyrics Editor.


First, to add an empty text at time 0, seek the movie to 0 and press the button to add at the current time without entering anything in the text box.
Next, seek the movie to the time you want the lyrics to change, enter the lyrics in the text box and press the button to add at the current time.
The lyrics will then be displayed. For times when you don't want to show lyrics, leave the text box empty and press the add button.
Lines are added at the current time of the movie. You can change the time by seeking to the desired time before pressing add, by shifting the time of the selected line, or by dragging and dropping the [L] mark on the timeline.

Next, events. (This may be a bit advanced)
Show the Event Manager from View → Event Manager.


Select Add Event to show the add event dialog.
In the Event Manager you can set the volume of each hit sound, the movie volume, whether to play a sound when a long note is released, BPM changes (soflan), stops, sudden, hidden and more.
Choose effects that suit the movie.
Events are added at the current time of the movie. You can change the time by seeking to the desired time before pressing Add Event, by shifting the time of the selected line, or by dragging and dropping the [E] mark on the timeline.
