说明歌词的设置方法。 从 视图→歌词编辑器 显示歌词编辑器。


首先，为了在时间0添加空文本，将视频定位到0后，不在文本框中输入任何内容，直接点击在当前时间插入的按钮。
接着，将视频定位到想切换歌词的时间，在文本框中输入歌词，然后点击在当前时间插入的按钮。
这样歌词就会显示出来。不想显示歌词的时间，请将文本框留空并点击添加按钮。
添加的时间为视频的当前时间。可以先定位到想设置的时间再点击添加，或使用“偏移选中行的时间”，或在时间轴上拖放[L]标记来更改时间。

说明事件。（可能稍微有点面向进阶用户）
从 视图→事件管理器 显示事件管理器。


选择添加事件后会显示添加事件对话框。
在事件管理器中，可以设置各击打音的音量、视频的音量、长按松开时是否播放音效、变速（soflan）、停止、Sudden、Hidden等。
请选择适合视频的效果。
添加的时间为视频的当前时间。可以先定位到想设置的时间再点击添加事件，或使用“偏移选中行的时间”，或在时间轴上拖放[E]标记来更改时间。
