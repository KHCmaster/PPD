# 実プレイ確認チェックリスト

移行の各フェーズの完了時（とリリース前）に、手で確認する項目です。自動の回帰テスト（`Tools/RenderCheck/RenderCheck.ps1`）では確かめられないものを並べています。
括弧内は、その項目で主に確かめたい変更です。

## 準備

- [ ] Debug と Release の両方をビルドし、Release の出力（`release\x64\PPD`）で確認する
- [ ] 既存の利用者データ（`PPD.ini`、`PPD.db`、`keyconfig.ini`、`mods\`、譜面フォルダー）のコピーを置いて起動する（設定・DB の互換）
- [ ] （任意）環境変数 `PPD_COM_DIAGNOSTICS=1` を付けて起動すると、終了時に `com_diagnostics.log` に DirectX などの解放漏れが書き出される（D3D11 のデバッグレイヤーが必要）

## PPD 本体

- [ ] 起動してタイトル・ホームが表示される。文字がつぶれたり欠けたりしていない（Direct2D / DirectWrite）
- [ ] 選曲画面: スクロール、プレビューの再生、難易度の切り替え
- [ ] キーボードで全ボタンが入力できる。ゲームパッドでも入力できる（DirectInput）
- [ ] プレイ: 判定、効果音、コンボ・スコア表示、ホールド・スライド（数学型、DirectSound）
- [ ] 動画付きの譜面: 動画が表示され、音とずれない。途中で抜けても落ちない（PPDMovie）
- [ ] リザルト: スコアが保存され、再度起動しても残っている（SQLite）
- [ ] リプレイの保存と再生（GZip の読み込み）
- [ ] Mod を有効にしてプレイする。Mod の設定画面で値を変えて保存し、再起動後も残っている（FlowScript、Mod の設定の保存形式）
- [ ] スクリーンショット（画像が保存され、内容が正しい）
- [ ] 全画面の切り替え、ウィンドウサイズの変更
- [ ] FPS が移行前と同等（設定で FPS を表示して、タイトル・選曲・プレイ中を比べる）
- [ ] ゲーム内の終了確認から終了し、エラーダイアログや `error.log` への書き込みがない

## マルチプレイ

- [ ] 部屋の作成・参加、チャット、曲の選択、プレイ、結果の表示（MessagePack の通信）
- [ ] 旧バージョンのクライアントまたはサーバーとの組み合わせ（互換の範囲の確認）

## PPDEditor

- [ ] 譜面を開く・保存する。プレビューの描画と再生（D3D11、DirectSound）
- [ ] マーカーの配置・移動・回転、ベジェでの配置（数学型）
- [ ] スクリプト（FlowScript）の編集・実行・停止（`Repeat.While` などの無限ループが止められる）
- [ ] 統計ウィンドウのグラフ
- [ ] キー設定（エディター内）で入力を割り当てられる
- [ ] メニューの「終了」で終了できる

## その他のアプリ

- [ ] PPDConfig: 各タブの表示、設定の保存と、PPD への反映
- [ ] KeyConfiger: キーボードとゲームパッドの割り当て、保存（`keyconfig.ini` の互換）
- [ ] PPDExpansion（PPD から起動）: 画面の表示、グラフ、終了
- [ ] Effect2DEditor、BMSTOPPD: 起動し、ファイルを開ける
- [ ] PPDUpdater / PPDInstaller（Phase 7 以降）: 更新とインストール
